# What is a network?

A network connects devices so that they can send each other messages. A message travels in small
pieces called **packets**. Every packet carries the address of its destination, much like a letter.

![Two PCs, each with a cable to a switch in the middle](img/netz.svg)

In the picture two PCs hang off a **switch**. It has many ports and remembers which device sits on
which port. When a packet arrives, it passes it on only where the destination sits.

## What to remember

- A **host** sends and receives messages, a PC or a server for instance.
- A **switch** connects the devices of a network with each other.
- A cable alone is not enough: the hosts need addresses too.
