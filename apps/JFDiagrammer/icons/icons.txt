# icons.txt -- every ribbon icon of JFDiagrammer (FEATURES.md 7): the table mkicons.py reads
#
# [part] starts a part; a row:   n | stem | sizes | prio | Name | Ort | Motiv
#   n      hex number: code point 0x10F200 + n (16 px), 0x10F600 + n (32 px); never reused
#   stem   the files icons/STEM_16.svg and STEM_32.svg, the constants JD_STEM and JD_STEM_L
#   sizes  16, 32 or "16 32": 16 for every ribbon command (any may land in the quick access
#          toolbar or a small button), 32 where FEATURES has a large button
#   prio   P1..P3 as in FEATURES
#   Motiv  a hint for the drawing (FEATURES' suggestion in our words), not a model to copy
# Numbers below 0x010 are the approved sample sheet (mkicons.py --sheet).  Galleries (designs,
# variants, quick styles, containers, callouts, data graphics, pens, layouts) get rendered
# previews, not drawn icons; the app logo has its own pipeline.  Language-dependent letters
# (bold, italic, underline) come once per letter; the app picks by UI language:
#   bold de F, en B, es N, it/fr G -- italic de/es K, en/fr I, it C -- underline de/en U, es/it/fr S
