# icons_fluent.txt -- glyph source of every icon in tools/icons.txt: Fluent UI System Icons
# (https://github.com/microsoft/fluentui-system-icons, MIT licence, see
# styles/winui/assets/LICENSE-FluentSystemIcons.txt; fonts/FluentSystemIcons-{Regular,Filled}.ttf
# and their .json name maps, commit 83b26348c811f072429427ff48362238656524fe).
# Format: "Name glyph" per line, '#' starts a comment.  ttf2bin stores the glyph at the icon's
# codepoint from icons.txt, so the IC_* constants (the former Segoe Fluent Icons codepoints) keep
# their values.  Size: the 16 px design where Fluent has one (1 px strokes at 16 px, the size the
# styles draw most icons at), else the 20 px design; regular unless the icon is a filled shape.
# Comments note where the Fluent shape differs from the former Segoe glyph.
# Regenerate styles/winui/assets/icons.bin (FLUENT = fonts/ directory of the repository above):
#   python tools/ttf2bin.py --font FLUENT/FluentSystemIcons-Regular.ttf
#       --font FLUENT/FluentSystemIcons-Filled.ttf --icons tools/icons.txt
#       --remap tools/icons_fluent.txt --out styles/winui/assets/icons.bin
