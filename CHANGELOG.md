# Changelog

All notable changes to the JFLib library -- the crates under `lib/`, the styles, the build
(`build_rs.py`) and its tools -- are recorded here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html) as
[docs/VERSIONING.md](docs/VERSIONING.md) describes (what is public, deprecations, how
`build_rs.py api-diff` checks a release). Apps keep their own versions (`version=` in
`apps/NAME/PACKAGE`) and their own notes.

Add entries with `python build_rs.py changelog "What changed" --type added|changed|deprecated|removed|fixed|security --area AREA`;
`python build_rs.py release X.Y.Z` turns `[Unreleased]` into a release.

## [Unreleased]

### Added

- **render3d:** The crate jflib-render3d (lib/render3d, in the facade as jflib::render3d), the core of the 3D engine on lib/gpu: meshes in shared buffers, a table of materials, scenes of instances with f64 positions relative to an origin, a camera with reverse Z, a sun, visibility in a compute shader and one instance list per mesh (one multi-draw on Voll, one indirect draw per list on Basis and in the browser), from the same WGSL; `render3dtest`, tested against a ray caster on the CPU (docs/RENDER3D.md)
- **gltf:** The crate jflib-gltf (lib/gltf, in the facade as jflib::gltf): glTF 2.0 import of .gltf (external files, data URIs) and .glb into a model without a GPU: triangles with positions, normals and uv (byte strides, normalized uv, sparse accessors, flat normals where the file has none), pbrMetallicRoughness materials with their five textures, PNG and JPEG images decoded by img_png and img_jpeg, samplers, nodes with f64 world matrices, the instances of a scene, decompose; files are checked as untrusted input and bounded by Limits, a required extension is Unsupported (docs/GLTF.md)
- **render3d:** Textures: one texture array per size class (128 to 2048) and colour space, chosen per instance through its material in the fragment shader, the same WGSL on Voll, Basis and WebGPU; mip levels by a box filter on the CPU (sRGB in linear light), other sizes resampled, glTF's wrap and filter modes done exactly in the shader with one sampler, alpha mode MASK; Material carries glTF's five textures and their factors for PBR; add_texture, texture_info, mip_chain (docs/RENDER3D.md)
- **render3d:** Mirrored instances: a transform with a negative determinant goes to its mesh's list of mirrored instances, drawn by a second pipeline with clockwise front faces and correct normals; negative scales are no longer Invalid
- **render3d:** render3d::gltf::upload puts a jflib-gltf Document on the GPU: its primitives as meshes, its images as textures, its materials, and the instances of a scene for Scene::add; render3dtest tests textures, mirroring and glTF against the ray caster and in the browser

### Changed

- **ui:** The built-in catalogue has no row "Neuer Ordner" any more: only JFNetworker used it, which keeps its own (`ui::i18n::t` falls back to the text itself).
- **gpu:** Validation with jfgui_GPU_VALIDATE now also checks what shaders read and write through their bindings (syncval_shader_accesses_heuristic, off in the layer by default): a missing barrier between two shaders no longer goes unreported
- The guide and the README install `cargo-jflib` from crates.io; the hint to install it from a checkout
  is gone. `tools/publish.py` keeps Cargo's output in `build/publish.log` too.
- **render3d:** A material row is 80 bytes (G5a: 64) and what reaches the colour target is opaque (alpha 1), as glTF wants for OPAQUE and MASK
- **render3d:** Sun::color is illuminance in lux (KHR_lights_punctual; Sun::DEFAULT 0.75 pi), materials are shaded as PBR instead of Lambert, nearest texture filtering loads the texel (textureLoad) instead of sampling its centre
- **img_core:** The MIME type of Paint.NET files is `image/x-paint.net` (it was `image/x-PaintCraft`, a leftover of a renaming).
- **plat:** The CoreCLR host's AppDomain is called `JFLib.ClrHost` (was `PaintCraft.PdnHost`).
- **Modules:** `modules/jxlenc` is built next to `codectest`, which loads it with `--jxlenc FILE` (`build_rs.py` APP_MODULES); `modules/modrt/mem.rs` is modrt's own file now (it was a copy of `lib/plugin/mem.rs`).
- **Tests:** `lib/text_shape`'s shaping test reads its font from `JFLIB_SHAPING_FONT` (was `PAINTCRAFT_SHAPING_FONT`); the codec checks' fixtures (`a1_rgba.png`, `a6_photo.png`, `pdn/`) are in `apps/codectest/fixtures/`.
- **rt:** rt::portable::math (rt::x87 on ARM64, Android and in the browser): pow, sin and cos within about half an ulp (were up to 118 ulp for pow and 1e-15 absolute for sin and cos, far worse beyond +-20): double-double intermediates without FMA, a table-driven log2 and exp2 inside pow, any finite angle reduced exactly (Cody-Waite below 2^19, Payne-Hanek above); still the same bits on every processor (docs/ARM64.md)
- **rt:** rt::portable::math (rt::x87 on ARM64, Android, Apple and in the browser): exp2, log2 and atan2 (and so rz_exp2, rz_log2) within about half an ulp (were up to 4, 5 and 5 ulp): exp2 and log2 from pow's double-double tables, atan2 from a table of atan(j/32) with a double-double quotient; subnormal results of exp2 and pow are rounded once; log10_round keeps its series and its x87 integers (docs/ARM64.md)
- **render3d:** The renderer's own depth buffer (Renderer::set_size) can be sampled (TextureUsage::SAMPLED), FrameStats::visible counts both phases of the occlusion test and FrameStats::draw both passes
- **render3d:** A view's uniform block is 208 bytes (UploadInfo::bytes of a frame without changes: 688); the bounding sphere of a mesh with detail levels holds every level
- **render3d:** Scene: which list an instance is in is settled by Scene::prepare (the class is its material's, which the renderer holds): add, remove, set_mesh, set_transform and set_material only mark it, Scene::lists shows what the last prepare settled, a material that changes its class through Renderer::set_material moves its instances with each scene's next prepare; draws_buffer, late_buffers and cascade_buffers hold a list's draw record at ListInfo::record (records lie by index width, class and side), no longer at the list's index; FS_SPV is now the opaque lists' fragment shader without discard

### Removed

- **JFNetworker** and **JFScript** moved to their own repositories, [JFLibrary/JFNetworker](https://github.com/JFLibrary/JFNetworker) and
  [JFLibrary/JFScript](https://github.com/JFLibrary/JFScript) (docs/CRATES.md, CR7 step 1): `apps/JFNetworker`, `apps/jfs` with the crate `script`
  (now `jfscript`), coretest's groups script, scriptvm, scriptlib, scriptls and scriptmod (JFScript's `scripttest`),
  `tools/academy_index.py`, `tools/academy_e2e.py` and `tools/script_math_check.py`. `editortest` takes JFScript from
  its repository, the workspace takes that repository's `jflib-agent-core` from itself (`[patch.crates-io]`);
  `symboltest` keeps a copy of JFNetworker's symbol table. The style `netlab` stays here.
- **PaintCraft** moved to its own repository, [JFLibrary/JFPainter](https://github.com/JFLibrary/JFPainter), as JFPainter (docs/CRATES.md, CR7 step 1), with its Rust plugins (`plugins/`, `lib/plugin`), its paint.net host (`tools/paintcraft-pdn-host`) and its check scripts; `build_rs.py plugin`, the plugin lint and the pdn-host section are gone, and so are the platshared comparisons that imported those scripts (`clip_rs_check`, `lib_check`, `print_rs_check`, the print part of `portal_bus`) and `pathdata_check`'s XAML fuzz through PaintCraft. `testenv` no longer sets `PaintCraft_CONFIG_DIR`.

## [0.1.0] - 2026-11-08

The first version on crates.io. It takes in the internal 0.1.0 of 2026-10-20, never published:
the Rust rewrite of jfguiLib, published as JFLib on 2026-10-14, and the roadmap work since then
([docs/ROADMAP.md](docs/ROADMAP.md)). Its public API is recorded in `docs/api/0.1.0.txt`.

### Fixed

- **build:** `build_rs.py release` writes cargo-jflib's version into Cargo.lock as well (before, `cargo --locked` failed after a release)
- **JFNetworker:** A device with many TCP connections, TIME-WAIT among them, spent its time looking for the next deadline on every segment; a load generator with thousands of requests in flight looked through its connections for each one. Both find them at once now: such runs take a seventieth to a five-hundredth of the time, with the same reports.
- **rt:** Small blocks of the allocator live in 64 heaps with a lock each, chosen by the stack's address, instead of one lock for all: threads that allocate all the time no longer wait for each other (a simulation's sweep took as long on 4 threads as on 1, and now under half).
- **JFNetworker:** A closed-loop load generator no longer stops for good when its target goes away and requests fail as they are made (no route, ARP gave up): it tries again every 100 ms
- **JFNetworker:** A script service with http.serve no longer stops after about 11 000 requests: what the service makes for a callback is collected also when the callback allocates nothing itself, and a request the handler cannot start for (heap full, frame too large) is answered 500 instead of staying open
- **JFNetworker:** At a full script heap nothing stays behind any more: callbacks of http.request, dns.resolve and disk run with the limit's text as err (they stayed pinned and never ran, a res waiting for them stayed open), a new connection is closed, one whose data does not fit is aborted, and the close callback still comes (with nil for its reason when that does not fit)
- **script:** The collector also runs for allocations the host makes between runs (Vm::new_str, new_map ..), so a host's arguments no longer fill the heap of a script that allocates nothing itself; what the host made since the last run stays alive until the next run, a value it took out of a pin only while the pin holds it
- **tests:** The cancellation, wake-up and download checks of plattest and coretest no longer race on a loaded machine
- **ui:** Text scale 150 to 200 %: bar chart column labels no longer run into each other (every k-th one, the first and the last kept, inside the chart; value steps a line apart), badges, grid headers, navigation items, segmented items, tabs, info bars, legend entries and text box placeholders that do not fit end with an ellipsis instead of a cut through a glyph, badge and navigation pills grow with the text (Ui::dp_text), donut centre texts stay inside the hole

### Security

- **plat:** Wayland: the sizes of the shared-memory buffers of windows and popups are computed without 32-bit wrap-around; a frame whose buffers would pass the protocol's 2 GiB pool limit stays unshown instead of being copied past the mapping
- **plat:** Windows: the single-instance pipe is used only when the SIDs of both processes were read and are equal (two failed lookups counted as the same user); device names and spell-checker strings are scanned with the length limit checked before each read
